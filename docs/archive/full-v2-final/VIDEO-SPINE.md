## Claims to avoid

- 'Astra verified every answer', 'human audited', 'publication-ready benchmark', '13 independent architectures', or '100,000 independent tasks'.
- Winnow's 500 errors as wrong decisions; current corrected registry as if it was used during this run.
- Dashboard pairwise strict intervals alongside the shared selected-label chart; use supplement's matching intervals.
- Judge ambiguity as credit for every possible answer; label-vector probability tasks as fully audited.
- Arabic locale metadata as guaranteed Arabic text, or RAG 93.6% as impressive without its 90.6% first-label control.
- Max-throughput ratios, optimized vendor comparisons, near-limit context performance, native support inferred from our configured context caps, or live customer-resolution claims.
- 'All models failed tickets' without showing that some deferred everything safely but uselessly.

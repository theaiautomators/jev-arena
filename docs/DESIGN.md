# Art direction

Visual thesis: a graphite broadcast desk, warm white typography and one sharp lime accent, with measured data as the dominant visual.

Content plan: persistent navigation; a comparison workspace with run control, quality/latency frontier and entrant table; live run inspector; case evidence; setup and provenance. The first viewport answers what is selected, what has been measured and what happens when Impress is pressed.

Interaction thesis: a short staggered workspace entrance; transitions that track selected entrants and their chart points; real event-driven progress with a restrained live cursor. Replay follows saved timestamps. Reduced-motion users get immediate state updates.
